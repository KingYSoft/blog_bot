## Method

The sole repository inclusion source was the live, official [GitHub Trending](https://github.com/trending) page under its default filters: **global, any spoken language, any programming language, Today/Daily**. The complete HTML was read from page heading to footer twice; both live reads returned the same 17 repositories in the same order. No cached list, search result, third-party ranking or extra repository was used. Every repository homepage and full README was then retrieved, while lifetime stars, primary language, license, archive status, open-issue count and push time were cross-checked through the official GitHub API. Lifetime stars can move after the stated capture time.

News selection separated the event date from publication time, favored first-party releases and public authorities, and used authoritative reporting for market synthesis or where a primary release was unavailable. Because the cutoff is early on August 12 in Europe and the Americas, the candidate pool includes late-August 11 events that remain current in Asia. Startup concepts were screened from the full 17-repository list and 20-story news pool, then constrained to one full-stack founder, a 1–2 week MVP, normally under $500 cash cost, direct online distribution and a paid-validation threshold. Trend data is treated as a demand signal, not proof of a market.

## 15 startup experiments for a solo software founder

The shortlist below came from a broader pool built from all 17 Trending repositories and all 20 selected stories. Scores are **solo executability + willingness to pay + acquisition ease + developer fit**, each 1–5. Every MVP is software-first, can use local/open-source components or free tiers, and is budgeted below **$500** for the first validation week. A trend link is evidence of active attention, not proof of purchase; each experiment therefore ends in money or a conditional purchase commitment.

### 1. SkillLock CI for agent-skill supply chains — **19/20 (5+5+4+5)**

- **Positioning:** A GitHub app that turns an imported agent skill into a pinned, permission-reviewed lockfile before it reaches a coding agent.
- **Pain / evidence:** Three skill catalogs occupy today's Trending page—[`agency-agents`](https://github.com/msitarzewski/agency-agents), [`agent-skills`](https://github.com/addyosmani/agent-skills) and [`anthropics/skills`](https://github.com/anthropics/skills)—while their READMEs can contain scripts, resources and tool assumptions. Existing substitutes are manual review, generic secret scanners and dependency bots; none understands skill manifests and prompt-requested actions. Purchase evidence is **to be validated**.
- **Customer / first 20:** 5–30-person software teams already checking agent skills into `.claude`, `.codex` or similar folders; first 20 are engineering leads in public repos that added or updated such directories in the last month.
- **Product / difference:** Resolve transitive files, flag shell/network/credential instructions, record source commit/license/hash and comment a human-readable permission delta on the PR. Unlike a generic SAST tool, it understands instruction files and skill layout.
- **Technical leverage:** GitHub webhooks, tree-sitter/semgrep-style rules, YAML/frontmatter parsing, Git object hashes and an LLM only for classified explanations—not for the blocking decision.
- **1–2 week MVP:** GitHub App install; scan changed skill folders; risk/permission diff; signed `skill-lock.json`; PR check. **Not doing:** malware guarantees, runtime sandboxing, private registry or every agent format.
- **Implementation:** TypeScript/Next.js, GitHub App/Checks API, Postgres/SQLite, OpenSSF Scorecard metadata and a small deterministic policy engine.
- **Business model:** $29/month for 5 repos or $99/year per private repo as a launch test; open-source local CLI for discovery.
- **First users / first outreach:** GitHub search for recently committed `SKILL.md`; send a maintainer a free scan with “I found these three unpinned external actions—want this as a PR check?”
- **7-day validation / payment gate:** Days 1–2 scan 30 public skills; 3 publish five annotated reports; 4–5 run ten calls; 6 install two pilots; 7 ask for payment. Pass at **3 paid teams or 5 written $29/month conditional commitments**. Stop if fewer than 3 of 20 calls report an actionable finding or no one will grant read-only install access.

### 2. Least-privilege credential gateway for persistent agents — **19/20 (5+5+4+5)**

- **Positioning:** A local proxy that gives long-running agents single-task, expiring API capabilities with human approval and a replayable audit trail.
- **Pain / evidence:** Grok Bot now uses logged-in tools, while [`orca`](https://github.com/stablyai/orca), [`paperclip`](https://github.com/paperclipai/paperclip) and [`prime-agent`](https://github.com/PrimeIntellect-ai/prime-agent) normalize remote or long-lived execution. - **Customer / first 20:** Small AI consultancies and dev shops running 3–20 agents against GitHub, Slack and Linear; start with founders visibly posting agent automation demos.
- **Product / difference:** Agents receive a localhost token that can call only pre-approved operations; the owner approves unusual parameters and sees spend/action history. It does not store general passwords or claim to replace enterprise IAM.
- **Technical leverage:** OAuth app tokens, JSON-schema operation policies, short-lived JWTs, an HTTP reverse proxy and Slack/email approval links.
- **1–2 week MVP:** GitHub issue/PR and Slack-message connectors; allow/deny rules; one-click approval; immutable JSON audit export; kill switch. **Not doing:** browser credentials, financial transactions, multi-tenant enterprise SSO or automatic remediation.
- **Implementation:** Go or TypeScript local daemon, SQLite append-only log, libsodium encryption, GitHub/Slack OAuth and Tailscale-compatible callback URLs.

- **First users / first outreach:** Reach agent builders in Orca/Paperclip discussions with a 45-second demo: “Your agent tried to create this external webhook; approve once or deny.”
- **7-day validation / payment gate:** Interview five users, map top 20 actions, build GitHub connector, shadow-log two workflows, then run three approval pilots. Pass at **3 paid pilots**; stop if users prefer all-or-nothing tokens or median workflows need more than five connectors before value appears.

## Three popular-looking directions rejected

1. **Another general agent operating system.** Today's page already includes Orca, Paperclip, Prime Agent and several skill ecosystems. A solo founder cannot differentiate, secure and distribute a broad orchestration platform in two weeks; the MVP would be a demo, not a buyable wedge.
2. **A universal AI tutor for everyone.** DeepTutor validates interest, but a general tutor needs curriculum rights, pedagogy, safety, memory and consumer acquisition. The narrower citation/regression tool sells to identifiable course creators without handling high-stakes teaching or child data.
3. **An autonomous stock-picking/trading bot.** `daily_stock_analysis` proves attention, not excess returns. Data licensing, look-ahead bias, changing markets, trust and financial-regulatory boundaries make paid signals a poor low-risk solo MVP; provenance QA is the safer software layer.
