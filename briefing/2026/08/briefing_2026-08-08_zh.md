## 适合个人软件创业者的 15 个实验

评分为 **个人可执行性 + 付费意愿 + 获客容易度 + 开发能力匹配度**，各 1–5 分。同分时按证据强度与拿到真实付款的速度排序。

### 1. Agent Skill 来源与风险扫描器

- **一句话定位：** “Agent Skills 的 Dependabot”，在智能体加载前发现指令变更、危险命令、缺少许可证与未固定的安装来源。
- **痛点与证据：** 第 2、4、5 名都是 skills 仓库，今日合计新增 **2,613 Star**；README 同时暴露多种安装器、reference 缺失和重复安装风险。团队会审代码依赖，却常让指令资产绕过供应链控制。
- **目标客户/首批 20 人：** 20 家公开仓库含 `SKILL.md`、`.agents/`、Claude plugin 或 agent installer 的 5–50 人 SaaS 团队安全/工程负责人。
- **方案与差异：** 盘点并 hash skill、做语义 diff、识别 shell/网络/凭据指令、在 PR 输出有引用的 gate；不同于通用密钥扫描，它理解 manifest、引用文件和指令到工具权限。
- **技术杠杆：** GitHub App、Markdown/AST、Semgrep 式规则与可签名清单，无需训练模型。
- **1–2 周 MVP/不做：** 扫一个 GitHub repo；解析本地和 GitHub 引用；10 条确定性规则；签名清单与 PR 评论。**不做** 恶意软件定性、全客户端、自动执行和企业策略平台。
- **实现建议：** TypeScript GitHub App、unified/remark、tree-sitter/bash parser、SQLite/Postgres、Sigstore。
- **商业模式/首发价：** 5 仓库 49 美元/月；带组织策略历史 149 美元/月。
- **首批获客/第一条外联：** 搜索公开 `SKILL.md`，私发一页差异报告：“你的 agent installer 拉取 3 个未固定指令集，要不要在下次更新前加一个有证据的 PR gate？”
- **7 天验证：** 1–2 天审计 10 仓库并访谈 5 人；第 3 天发布 inventory；4–5 天发 30 份个性扫描；6–7 天安装两个付费 pilot。
- **首个付费门槛：** 3 家团队为私有仓库检查支付至少 49 美元；扫描量、Star、waitlist 不算。
- **风险/最快证伪/止损：** 买家可能认为 skill 只是文本，或完全依赖 marketplace。30 次合格外联、5 次 demo 后少于 2 家付款，或没有发现改变安装决策，就停止。
- **评分：** **5 + 5 + 4 + 5 = 19/20**。

### 2. AI 智能体网络安全评测隔离器

- **一句话定位：** 本地 harness，证明网络安全 agent 测试始终留在授权目标、凭据和出口边界内。
- **痛点与证据：** Meta 披露错误配置让模型上网并利用第三方；Prime Agent 也明确命令使用用户权限。现有 benchmark 重能力，轻授权证据。
- **目标客户/首批 20 人：** 20 家公开运行 agentic cyber eval 的小型模型实验室或安全咨询公司的 AI 安全工程师。
- **方案与差异：** 生成 allowlist、临时凭据、网络策略、工具调用收据与签名例外报告；这是隔离/证据层，不是攻击 agent。
- **技术杠杆：** 容器、eBPF/网络日志、policy-as-code 与签名 manifest，无需自建模型或漏洞语料。
- **1–2 周 MVP/不做：** 包装一个 Docker agent；域名/IP 白名单；secret canary；出口/工具日志；签名报告。**不做** 漏洞生成、生产 SOC、任意云编排和安全认证。
- **实现建议：** Go CLI、Docker、Cilium/Tetragon 或 nftables、OPA/Rego、gitleaks、in-toto/Sigstore。
- **商业模式/首发价：** 每评测 workspace 199 美元，或 149 美元/月。
- **首批获客/第一条外联：** 联系公开论文/仓库作者：“你上次报告能证明每个数据包和凭据都在范围内吗？我可本地复跑一次。”
- **7 天验证：** 访谈 4 名评测者；复现一次合成越界；完成 wrapper；跑 3 个授权试验；新增云支持前先收费。
- **首个付费门槛：** 2 家团队各付 199 美元，并把报告放入内部 review。
- **风险/最快证伪/止损：** 漏掉系统级越界会制造虚假安全感。20 个红队案例漏掉任何已知出口，或 5 名评测者都拒绝串联使用，就停止。
- **评分：** **4 + 5 + 5 + 5 = 19/20**。

### 3. Authentik 配置变更检查器

- **一句话定位：** 面向小团队 authentik SSO 的部署前 diff、角色回归与回滚验证器。
- **痛点与证据：** authentik 排第 6、今日 +467，协议很多；一个 flow、claim、group 或 outpost 改动就可能锁号或越权，完整身份测试套件又昂贵。
- **目标客户/首批 20 人：** 20 个用 authentik 管理 10–200 用户、至少 5 个应用的自托管 SaaS 运维或 homelab 咨询商。
- **方案与差异：** 快照配置，模拟 5 类登录角色，diff claim/group/policy，验证 break-glass 并生成回滚步骤；不同于上线监控，它先测授权意图。
- **技术杠杆：** authentik API/blueprint、Playwright 与确定性角色 fixture。
- **1–2 周 MVP/不做：** 单实例；配置快照/diff；5 个合成用户；OIDC 登录测试；加密回滚包。**不做** 新 IdP、SAML 迁移、密码存储和自动生产回滚。
- **实现建议：** Python、authentik API、Playwright、pytest、age 加密、GitHub Actions。
- **商业模式/首发价：** 每实例 39 美元/月；升级单次核验 149 美元。

- **实现建议：** Next.js、Docker lab、GitHub/Gist 证据、rubric engine、Stripe link。
- **商业模式/首发价：** 每岗位/公司 sprint 39 美元。
- **首批获客/第一条外联：** “你的目标岗位常问 Kubernetes 事故；这是一个 20 分钟 lab 和证据 rubric，39 美元解锁完整 7 天包。”
- **7 天验证：** 访谈 10 候选人；做 3 lab；招募 20 prospect；扩公司前先收完成和付款数据。
- **首个付费门槛：** 10 人各付 39 美元，且 5 人完成 2 个 lab。
- **风险/最快证伪/止损：** 数据可能保密或过时。无法显示来源、客户只要背答案，或 20 prospect 少于 3 个付款，就停止。
- **评分：** **5 + 3 + 5 + 3 = 16/20**。

### 14. 课程 PDF 权利与无障碍盘点器

- **一句话定位：** 小型学校本地扫描 PDF 来源、许可证据、阅读顺序、OCR 和坏链的工具。
- **痛点与证据：** ChinaTextbook 单日 +591 说明数字课程有需求，但缺许可证元数据、拆分文件和 PDF 密集结构暴露版权、完整性与无障碍问题；学校替代方案仍是网盘和表格。
- **目标客户/首批 20 人：** 20 家拥有 100–2,000 PDF 的独立中文学校或 nonprofit 补习项目数字学习负责人。
- **方案与差异：** hash 文件，找重复/拆分，记录权利证据，测试 OCR/阅读顺序并导出修复队列；不同于文档库，它不托管、不再分发内容。
- **技术杠杆：** PDF 元数据、OCR、hash 和无障碍 heuristic 可完全本地运行，无需专有语料。
- **1–2 周 MVP/不做：** 文件夹扫描；重复/拆分；rights-status 字段；OCR/text coverage；CSV/HTML 报告。**不做** 内容下载、法律清权、LMS 和自动再发布。
- **实现建议：** Python CLI、pypdf、OCRmyPDF/Tesseract、感知 hash、本地 SQLite。
- **商业模式/首发价：** 2,000 文件审计 149 美元；重扫 29 美元/月。
- **首批获客/第一条外联：** “这份报告显示哪些 PDF 没来源、无文本层或重复拆分；能否在本地扫一个文件夹？”
- **7 天验证：** 访谈 5 协调员；审 2 个授权目录；量化工作量；联系 20 学校；卖 3 次审计。
- **首个付费门槛：** 3 个组织各付 149 美元，并修复至少 10 个文件。
- **风险/最快证伪/止损：** 权利仍需人工判断，预算也低。用户要求工具“证明合法”，或 20 学校少于 2 个付款，就停止。
- **评分：** **5 + 3 + 4 + 4 = 16/20**。

### 15. 地区 SaaS 可达性证据监控

- **一句话定位：** 合规诊断服务，告诉小 SaaS 团队某地区故障来自 DNS、TLS、CDN、路由还是应用。
- **痛点与证据：** fanqiang 的持续热度说明区域访问问题真实存在，但不安全 bundle 和不可验证 endpoint 不能作为产品基础；国际 SaaS 支持仍靠截图猜“是不是被封”。
- **目标客户/首批 20 人：** 20 家在公开 issue 中出现中国大陆或一个指定地区访问故障、员工少于 100 人的开发者 SaaS 支持/运维负责人。
- **方案与差异：** 只对客户自有域名做授权探针，对比 DNS/TLS/HTTP trace，保留证据并提出 CDN/域名/配置等中性修复；不绕过限制。
- **技术杠杆：** 第三方 probe API、证书透明度、DoH 和 synthetic check。
- **1–2 周 MVP/不做：** 一个地区；3 个 probe 网络；DNS/TLS/HTTP diff；事故时间线；支持导出。**不做** VPN/代理、规避审查、转发流量和法律结论。
- **实现建议：** Go probe、RIPE Atlas/经批准地区 monitor、DNS/CT API、Postgres、状态邮件。
- **商业模式/首发价：** 5 域名 49 美元/月；事故报告 99 美元。
- **首批获客/第一条外联：** 私下回复公开可达性 issue：“我拿到 3 条地区 trace，能区分 DNS 与应用故障；要不要一份带时间证据的支持报告？”
- **7 天验证：** 收集 20 个公开事故；与 5 团队核验；做 10 报告；预售持续监控。
- **首个付费门槛：** 3 家为事故付 99 美元，或 2 家订阅 49 美元。
- **风险/最快证伪/止损：** 探针合法性、代表性与归因随地区变化。拿不到合规授权探针立即停止；20 leads 后报告未改变任何修复决策也停止。
- **评分：** **4 + 3 + 4 + 5 = 16/20**。

## 本次淘汰的 3 个热门方向

1. **通用自主编程智能体：** Prime Agent 与 skills 很热，但个人开发者两周无法在通用 harness 上形成优势；模型、信任、隔离与分发都太重。窄验证工具更容易收费。
2. **AI 选股或自动心理治疗：** TradingAgents 与 chatbot 新闻都证明需求，但两者替代高风险持牌判断，带来不可接受的安全、受托与监管风险；只保留证据、教育和人工复核工具。
3. **教材下载镜像或翻墙软件包：** 注意力真实，但版权不清、地区法律、非可信二进制、滥用和长期内容运营都违反低风险软件筛选；本地盘点与中性可达性诊断更安全。
