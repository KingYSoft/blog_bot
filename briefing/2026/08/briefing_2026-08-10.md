## Method

The sole inclusion source for repositories was the live, official [GitHub Trending](https://github.com/trending) page with its default filters: **global, any spoken language, any programming language, Today/Daily**. The page was read from heading through footer, reloaded, and read again; both passes returned the same 12 repositories in the same order. No search page, cached list, third-party ranking, or extra repository was used. Each repository page and README was then read, and lifetime stars, language, license, and push time were cross-checked through the official GitHub API. Small differences between the page's displayed lifetime stars and API totals can occur while stars continue to arrive.

News was selected from developments still materially current at the cutoff, with event date separated from publication date. The Monday-morning window had few fresh corporate releases, so the pool combines consequential August 6–8 events with newly verified August 7 updates that remained prominent at the cutoff. Older stories resurfacing on current hubs were excluded after checking the underlying event date. Numerical claims were checked against primary releases where available. Startup ideas were screened from the full 12-repository list and 20-story news pool, then constrained to one full-stack founder, a 1–2 week MVP, usually under $500 cash cost, direct online distribution, and a real paid-validation gate.

## Three popular-looking directions rejected

1. **A general-purpose autonomous “AI agency.”** Popular repositories validate interest in reusable roles, but a broad agency product has no narrow buyer, expensive evaluation, weak differentiation, and high tool-permission risk. The viable wedge is provenance or role-pack evaluation, not another catalog.
2. **An AI stock-picking or auto-trading app.** The trending stock project and weak-trust finance survey show demand, but advice liability, data licensing, broker integration, misleading backtests, and crowded acquisition violate the low-risk two-week constraint. Source-freshness and leakage testing are safer picks-and-shovels.
3. **A hosted universal coding-agent control plane.** `prime-agent` and `t3code` make the idea exciting, but securely hosting credentials, arbitrary code execution, remote machines, and multiple providers is beyond a <$500 solo MVP. A local approval ledger or regression harness is a bounded entry point.
