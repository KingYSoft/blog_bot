## 方法说明

热门仓库唯一入选来源是实时官方 [GitHub Trending](https://github.com/trending) 页面，采用默认筛选：**全球、任意口语、任意编程语言、Today/Daily**。从标题一直读取到页脚，刷新后再次完整读取；两次均得到相同的 12 个仓库及顺序。没有使用搜索页、缓存榜单、第三方榜单，也没有添加页面之外的仓库。随后逐项读取仓库主页与 README，并通过 GitHub 官方 API 交叉核对总 Star、主要语言、许可证和最近推送时间。页面仍在持续获得 Star，Trending 页面与稍后 API 采集值出现个位数差异属于正常情况。

新闻只选在截止时点仍具有现实影响的事件，并将“事件发生日期”与“文章发布时间”分开核对。本次处于周一上午窗口，新增公司公告较少，因此新闻池把 8 月 6–8 日仍具影响的事件与刚核实的 8 月 7 日更新合并。对当前聚合页重新浮现的旧闻，核对实际事件日期后予以排除。涉及数字时尽量查阅原始公告。创业点子来自全部 12 个仓库和 20 条新闻形成的候选池，再按一名全栈开发者、1–2 周 MVP、原则上不超过 500 美元、可直接触达客户及真实付费门槛筛选。

## 面向个人软件创业者的 15 个实验

评分依次为**个人可执行性 + 付费意愿 + 获客容易度 + 开发能力匹配度**，每项 1–5 分。总分相同者按证据强度和付费验证速度排序。以下都是实验方向，不建议自动化受监管的专业判断。

### 1. Agent 评测隔离预检 — **19/20**

- **一句话定位：**在 AI Agent 评测启动前，扫描网络、凭据和目标配置并阻止越权运行的本地/CI 工具。
- **痛点与证据：**8 月 6 日 Meta/评测方事故表明，边界配置错误可让模型攻击第三方；`prime-agent` 也明确提醒会以用户权限执行代码。买家目前靠 Docker 规则、云 IAM 和人工清单拼接防线。
- **客户 / 首批 20 人：**运行网络、浏览器或编程 Agent 评测的 5–50 人 AI 创业公司安全工程师或 ML 平台负责人；从 OWASP GenAI、MLOps Community 和公开评测框架维护者中找 20 人。
- **方案 / 差异 / 技术杠杆：**解析声明式评测配置，解析可达主机与密钥权限，生成签名允许列表和证据。区别于通用容器扫描：理解 Agent 工具、目标授权与出站流量。利用 OPA/Rego、Docker API、GitHub Actions。
- **1–2 周 MVP：**CLI、YAML 策略、DNS/CIDR 与凭据范围检查、干运行连通图、SARIF/Markdown 报告。**明确不做：**运行时沙箱、真实攻击和自动修复。
- **商业化 / 获客：**49 美元/仓库/月或 199 美元一次配置。先发布事故驱动的最小清单，再给 20 位框架维护者私信，免费扫描一份公开配置。
- **7 天验证 / 付费门槛 / 止损：**前两天访谈 5 队，第三天解析配置，第四天扫 3 个仓库，第五天交报告，第六天问付费，第七天整理反对意见。门槛：**3 个付费试点或 5 份 49 美元有条件承诺**。若两队都无法提供真实配置，或云原生策略已完全覆盖则停止。评分 **5+5+4+5**。

### 2. Agent 技能来源与兼容性扫描器 — **19/20**

- **一句话定位：**清点 Agent 技能、标记高风险指令并检查 Codex、Claude、Cursor、Gemini 打包兼容性的 CLI/GitHub App。
- **痛点与证据：**`agent-skills`、`google/skills`、`agency-agents` 今日合计新增 1,706 Star；README 直接暴露引用文件缺失、开发中和平台数量限制。用户复制 Markdown 和脚本时没有锁文件和权限清单。
- **客户 / 首批 20 人：**10–100 人软件团队中管理共享 Agent 配置的资深工程师；从三类技能仓库 Issue 评论者、公开采用者和 AI 辅助开发机构中找 20 人。
- **方案 / 差异 / 技术杠杆：**生成技能 BOM 和来源哈希，识别 Shell、网络和密钥指令，并运行目录兼容检查。它做 Agent 技能语义与跨框架兼容，而非通用 SCA。利用 Markdown AST、GitHub API、Semgrep/Gitleaks。
- **MVP：**本地清单、来源锁文件、静态规则、三框架兼容矩阵、CI 报告。**不做：**恶意软件裁决、自动安装和企业策略编排。
- **商业化 / 获客：**29 美元/团队开发者/月或 99 美元/仓库审计。开源锁文件格式，为 3 个热门技能仓库发布免费报告并联系维护者。

## 本次淘汰的 3 个热门方向

1. **通用“自主 AI 代理公司”。** 热门仓库证明角色复用有兴趣，但宽泛代理公司没有窄买家，评测昂贵、差异弱、工具权限风险高。可行切口是技能来源或角色包评测，而不是再做一个角色目录。
2. **AI 选股或自动交易应用。** 股票项目和金融 AI 低信任调查都说明需求存在，但建议责任、数据许可、券商接入、回测误导和拥挤获客不符合低风险两周约束。来源新鲜度和前视偏差检查才是更安全的卖铲子机会。
3. **托管式通用编程 Agent 控制平面。** `prime-agent` 与 `t3code` 很有吸引力，但安全托管凭据、任意代码执行、远程机器和多提供商远超 500 美元个人 MVP。先做本地审批账本或回归测试框架更可控。
