## Method

Repository inclusion used only the live official [GitHub Trending](https://github.com/trending) page under its default filters: **global, any spoken language, any programming language, Today/Daily**. I read the full page through its footer, then repeated the read using the explicit daily URL. Both snapshots contained the same 17 repositories in the same order; no search result, cached or third-party ranking, or extra repository was used. For every entry, I read the repository homepage and README and cross-checked primary language, lifetime stars, push time, license and issue activity through the official GitHub API. Counts are point-in-time snapshots.

News screening distinguishes event date from publication date, favors regulators, company releases and other primary records, and uses authoritative reporting for market context. Late-August 13 events remain current at the August 14 Shanghai cutoff. Material figures were cross-checked where practical. Startup ideas were screened from the complete 17-repository list and the 20 selected stories against one builder, 1–2 weeks, normally under $500, direct online distribution and a paid-validation threshold. Attention is a demand signal, not proof of purchase.

## 15 startup experiments for a solo software founder

The candidate pool started with 31 directions derived from all 17 Trending repositories and the 20 selected stories. The following survived the hard constraints and are ordered by score. Scores are **solo executability + willingness to pay + acquisition ease + developer fit**, each 1–5.

### 1. Agent-skill permission and supply-chain linter — **19/20 (5+5+4+5)**

- **Positioning:** A GitHub Action that tells teams exactly what a downloaded Agent Skill can read, write, execute and call before installation.
- **Pain / evidence:** `anthropics/skills`, `obsidian-skills`, `agency-agents`, `diagram-design` and `holaOS` all make skills/plugins a distribution surface; the READMEs themselves tell users to install executable packages. Static permission receipts exist in mobile stores but are missing here. Willingness to pay is **to validate**.
- **Customer / first 20:** Maintainers of 5–50-person AI-native software teams using Claude Code, Codex or OpenCode; find 20 via recent GitHub issues/PRs in skill marketplaces and security-minded agent communities.
- **Product / difference / leverage:** Parse `SKILL.md`, manifests and scripts into a permission graph, flag shell/network/secret access and diff risk between versions. Unlike generic SAST, rules understand agent-skill conventions. Leverage tree-sitter, Semgrep and GitHub Checks.
- **1–2 week MVP:** repository scan, permission inventory, five high-signal rules, version diff and PR comment; **not** a malware verdict, sandbox or runtime blocker.
- **Implementation:** TypeScript worker/CLI, tree-sitter/bash parser, GitHub App/Actions, SQLite/Postgres; optionally ingest Agent Skills spec.
- **Business / price / channel:** $19/repository/month or $149 one-time organization audit. Publish a free scanner on GitHub Marketplace; first outreach: “I found two undeclared capabilities in this skill—want the private diff on your repos?”
- **7-day validation / paid bar:** Days 1–2 scan 100 public skills, 3 publish an anonymized risk taxonomy, 4–5 send 30 tailored diffs, 6 run five calls, 7 ask for payment. Pass at **3 paid repositories or 5 conditional $19 commitments**.
- **Risk / falsification / stop:** False positives or no buyer ownership. Fastest disproof: maintainers say native review is sufficient. Stop after 30 qualified contacts and five demos with zero paid intent.

### 2. OCR layout regression bench for document teams — **19/20 (5+5+4+5)**

## Three popular-looking directions rejected

1. **Another all-in-one agent workspace.** Macro and holaOS validate attention, but a solo founder cannot reproduce email/chat/docs/CRM/browser integrations, permissions, sync and reliability in two weeks; long migration cycles violate the constraint.
2. **Consumer local AI super-app.** Unsloth, FluidVoice, Modly and LTX-2 make it tempting, but hardware support, model downloads, safety and broad UX create a support-heavy commodity product with unclear direct distribution.
3. **Autonomous trading or central-bank predictor.** Inflation, BOJ and FX intervention news is attractive, but reliable proprietary data, regulated/high-risk decision boundaries and trust requirements exceed a low-cost solo MVP. A timestamped research aid could be safe; an execution system is excluded.
